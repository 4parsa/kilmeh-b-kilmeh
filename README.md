# كلمة بكلمة (Kilmeh b Kilmeh)

*"Word by word"*: a personal Lebanese Arabic dictionary I'm building to keep track of the words I learn.

I'm learning Lebanese Arabic and wanted one place to save new words as I pick them up, with the grammar forms that normal dictionaries skip (dual, sound and broken plurals, verb forms, etc.). It syncs between my phone and laptop so I can add words wherever I am.

🔗 **Live site:** https://4parsa.github.io/kilmeh-b-kilmeh/

## Features

- [ ] Add words (English, Arabic script and transliteration)
- [ ] Save words so they're still there after a refresh
- [ ] Search in English, Arabic or transliteration
- [ ] Edit and delete words
- [ ] Extra forms depending on word type (plurals for nouns, conjugations for verbs, gender forms for adjectives)
- [ ] Flashcard mode for revision
- [ ] Sync across devices with a cloud database
- [ ] Login so only I can edit
- [ ] Installable on my phone's home screen (PWA)

## Built with

- HTML, CSS, JavaScript (no frameworks)
- Supabase (PostgreSQL database + authentication)
- GitHub Pages for hosting
